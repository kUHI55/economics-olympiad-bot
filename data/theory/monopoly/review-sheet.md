# Памятка: монополия

## Базовые формулы

- `TR(Q)=P(Q)Q`; `π(Q)=TR(Q)−TC(Q)`; `MR=dTR/dQ`; `MC=dTC/dQ`.
- Для обратного линейного спроса `P=a−bQ`: `TR=aQ−bQ²`, `MR=a−2bQ`.
- Единый ценник: гладкое внутреннее условие-кандидат `MR=MC`. Нужны проверка второй производной, `Q=0`, границ, мощности, изломов, скачков и всех режимов; сравнивайте полную прибыль.
- Не путать монополию и конкуренцию: при совершенной конкуренции `P=MR`; для обычного нисходящего спроса монополиста при `Q>0` обычно `MR<P`.

## Налоги и эластичность

- Потоварный налог `t`: `π=TR−TC−tQ`, кандидат `MR=MC+t`.
- Налог на выручку `t`: `π=(1−t)TR−TC`, кандидат `(1−t)MR=MC`.
- Налог на прибыль `t`: `π=(1−t)(TR−TC)`; при `0≤t<1` стандартный выбор `Q` не меняется.
- Налоговые сборы: `R(t)=tQ(t)` — отдельная цель, не прибыль фирмы.
- Индекс Лернера: `(P−MC)/P=−1/ε`, `ε=(dQ/dP)(P/Q)<0`; только при классическом гладком внутреннем оптимуме.

## Сегменты и дискриминация

- Одна цена нескольким группам: горизонтально сложить количества по цене; если `P` выше резервной цены группы, её спрос равен нулю. Построить кусочные `Q(P)` и `P(Q)`.
- Первый род: индивидуальная цена, `MR=P`; кандидат `P(Q)=MC(Q)`.
- Второй род: меню; проверить участие и совместимость стимулов каждого типа. Для двухчастного тарифа `C=A+Px` проверить извлечение платежа и участие.
- Третий род: для активных рынков `MRi=общая MC(ΣQi)`; закрытые рынки проверить отдельно. При общей переменной `MC` рынки оптимизируются совместно.

## Потолок и сложные издержки

- Потолок `P̄`: найти свободный режим, горизонтальный участок `MR=P̄`, точку переключения и кусочную реакцию; при убыточности сравнить с `Q=0`.
- При кусочной/немонотонной `TC`/`MC`: кандидаты каждого участка только внутри него, плюс стыки, скачки, допустимые границы и нулевой выпуск; выбрать по полной прибыли.
- В дискретных задачах сравнивать суммарные приращения прибыли; не применять производную там, где объём неделим.

## Другие конструкции

- Межвременные продажи: вывести остаточный спрос каждого периода и максимизировать общую прибыль совместно.
- Международный посредник: найти направление торговли, выразить страны через общий объём `Q`, максимизировать `(цена продажи−цена закупки)Q`.
- Монопсония труда: вывести `MRP_L` и сопоставить с предельными расходами на труд; при минимальной зарплате проверить каждый режим занятости.
- Несколько товаров/ограничение затрат: оптимизировать совместно; проверить активность и выполнимость ограничения.

## Быстрая карта метода

| Признак в условии | Первый шаг |
|---|---|
| Один рынок и единая цена | Обратный спрос, `TR`, `MR`, `MC`; кандидаты и границы |
| Кусочные/скачкообразные затраты | Разбить на участки; сравнить полную прибыль по всем кандидатам |
| Группы при общей цене | Горизонтально сложить спрос с нулевыми ветвями |
| Разные цены | Определить род дискриминации: индивидуальная, самоотбор или сегменты |
| Потолок цены | Построить режимы `MR`, точки соединения и проверку закрытия |
| Налог | Уточнить базу налога до записи функции прибыли |
| Несколько периодов | Учесть остаточный спрос после ранних продаж |
| Труд как вход | Вывести `MRP_L`, затем кривую предельных расходов/режим минимума |
| Условие и ключ расходятся | Пересчитать из буквальной постановки и явно указать расхождение |

Показывайте подстановки и ход решения. Не называйте `MR=MC` доказательством глобального максимума без проверки; не переносите ответ ключа на другую постановку.
