# Краткая памятка: «Полезность и потребитель»

## 1. Перед вычислениями

Запишите функцию полезности, цены, доход и все ограничения. Проверьте, что выбор может быть внутренним: товары могут быть целочисленными, насыщенными, комплектными, ограниченными по времени или доступными только дискретно. Не предполагайте автоматически, что весь доход расходуется.

## 2. Базовые формулы

| Ситуация | Запись из конспекта |
| --- | --- |
| Бюджет | `pₓx + pᵧy ≤ I`; наклон `−pₓ/pᵧ`. |
| Предельные полезности | `MUₓ = ∂U/∂x`; `MUᵧ = ∂U/∂y`. |
| Гладкий внутренний оптимум | `MUₓ/pₓ = MUᵧ/pᵧ`; применяйте лишь после проверки условий. |
| Наклон кривой безразличия | `dy/dx = −MUₓ/MUᵧ`. |
| Cobb–Douglas | При `U=xᵅyᵝ`: `x*=αI/[(α+β)pₓ]`, `y*=βI/[(α+β)pᵧ]`. |
| `U=xy` | `x*=I/(2pₓ)`, `y*=I/(2pᵧ)`. |
| Совершенные комплементы | Для `U=min(ax,by)` сначала `ax=by`, затем учитывается бюджет. |
| Доходная эластичность | `Eᵢˣ=(∂x/∂I)(I/x)`. |
| Ценовая эластичность | `Eₚₓˣ=(∂x/∂pₓ)(pₓ/x)`. |
| Перекрёстная эластичность | `Eₚᵧˣ=(∂x/∂pᵧ)(pᵧ/x)`. |
| Риск | `E[U]=ΣpᵢU(Wᵢ)`; `U(CE)=E[U]`; премия `E[W]−CE`. |
| Труд и отдых | `L+l=T`; внутреннее условие `MU_l/MU_C=w`. |
| Межвременной бюджет | `c₁+c₂/(1+r)=s₁+s₂/(1+r)` при единой ставке. |

## 3. Алгоритм

1. Определите тип полезности: Cobb–Douglas, линейная, min/max, выпуклая, кусочная, с насыщением или дискретная.
2. Выберите допустимый метод: прямое ограничение, предельные полезности на рубль, линии уровня либо сравнение кандидатов/перебор.
3. Проверьте внутренние решения, углы, изломы, границы и целые корзины.
4. Сравните значения полезности кандидатов; отдельно установите, расходуется ли весь бюджет.
5. При изменении параметров найдите пороги и запишите решение по случаям.
6. Сформулируйте результат словами и укажите единицы.

## 4. Не забывайте

- Равенство `MUₓ/pₓ = MUᵧ/pᵧ` само по себе не доказывает глобальный максимум.
- Для выпуклой полезности сравнивайте угловые стратегии с внутренними кандидатами.
- Для комплектов, подарков и возрастающей предельной полезности сравнивайте полные корзины и пороговые бюджеты.
- При изменении цены отделяйте эффекты замещения и дохода; различайте компенсированные варианты Хикса и Слуцкого.
- В задачах о риске усредняйте полезность исходов, а не подменяйте её полезностью среднего богатства.
- В задаче о первоначальном запасе учитывайте стоимость обмена относительно исходной корзины.
- Сверяйте ответ с исходными данными и ключом. В частности, формула для задачи 3(д) в конспекте помечена как требующая проверки по исходному скану; расхождение задачи 13(г) не скрывается.
